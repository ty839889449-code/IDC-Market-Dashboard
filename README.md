# TECNO市场机会看板

这是一个可直接部署到 GitHub Pages 的静态网页版本，包含 24 个去重市场、9 档价位，以及国家 × 品牌 × 价位三层交互分析。

> 同步状态：已与公开看板第 15 版校准（2026-07-27）；`index.html` 与当前线上源码一致。

市场详情按照“容量趋势—价格迁移—品牌让渡—TECNO 基本盘—产品线承接”的方法分析存量与换机机会。“近 24 个月可观察存量”使用连续季度 Sell-in 累计作为代理值，并对比前后两个滚动 12 个月，判断市场扩张、收缩与结构迁移；它用于观察未来换机来源，不等同于在网活跃设备量。

在大盘价位变化与高端结构之间，还包含“各品牌分价位段同比增量与比例”：可切换品牌，查看九档价位的 25Q1、26Q1、同比净增量、同比增速和档内份额。24 个市场均已使用随本次版本更新的 IDC 源表补齐品牌 × 价位拆分；EE1（俄罗斯）与俄罗斯已合并为一个市场。

每个价位段先在 TECNO 整体层统一呈现市场背景，再分别给出 CAMON、POVA、SPARK 的机会等级、产品机会、当前阵地、竞争占位、核心竞争机型与进入条件，避免重复展示相同的价位段理解。

“各价位段核心产品”已重组为“价位概览 → 机型选择 → 产品图 → 核心数据 → 竞争分析 → TECNO 承接”六步结构。Top 3 机型以带图片的卡片直接点选，再切换“竞争占位、市场反馈、优势/短板、转化机会”四个页签；产品视觉、销量、卖点、官网参数与竞争判断保持同屏，TECNO 整体及 CAMON、POVA、SPARK 的承接建议改为按需展开，显著减少连续长卡片。高频机型优先使用品牌官网产品图；官网缺少稳定精确型号素材时，使用 GSMArena 的精确型号图片候选补充，并在图片角标中明确标注、跳转回对应机型页或型号检索页；候选无法加载时自动显示“产品示意图”，避免破图或近似机型错配。当前各市场各价位 Top 3 产品共 620 个展示位置，619 个已配置品牌官网或 GSMArena 精确型号图片候选；仅合并口径“iPhone 17 Pro / Pro Max”保留示意图，避免用单一机型图片代表组合记录。

Top 机型的“竞争角色”已升级为竞品用户转化分析，逐款呈现：

- **友商核心卖点**：沿用产品/系列竞争框架，并由对应品牌官网核验精确卖点与参数。
- **IDC 当前市场反馈**：展示 26Q1 出货、档内列示排名与份额、品牌同比和价位同比；该反馈指市场数据，不替代消费者口碑调研。
- **TECNO 对位**：根据价位、产品特征与系列边界，判断由 CAMON、POVA 或 SPARK 承接，以及对应的机会等级。
- **我方优势与短板**：优势表示按当前系列定位可以建立的相对优势；短板标记进入竞争必须补齐的能力，不把规划方向写成已量产事实。
- **可见进攻点与转化抓手**：结合友商品牌增长或份额让渡，给出现场演示、内容传播、以旧换新、更新/售后承诺及渠道话术等用户转化动作。

核心产品数据采用双来源结构：

- **IDC 数据**：市场规模、同比增量、价位段、机型排名和出货量。
- **产品竞争框架**：按产品/系列整理“竞争角色”、短标签式核心卖点和购买理由，不使用泛化品牌模板。
- **品牌官网**：Top 销量机型的屏幕、影像、芯片、电池、快充、防护等精确配置，优先关联当前所选国家官网；当地缺页时依次使用同区域国家官网、品牌全球官网或品牌国际站。
- **GSMArena 图片**：仅在品牌官网图片素材缺失时补充精确型号外观图；用于页面视觉展示，不替代品牌官网参数核验。
- **来源状态**：“本国官网”表示当前市场官方产品页；“同区域官网”会显示替代来源国家；“官网版本差异”表示 IDC 型号与官网地区版/5G 后缀存在差异；“官网待核验”不展示未经确认的精确参数。

当前版本共有 983 个产品展示行，其中 895 行由品牌官网支撑，覆盖所展示出货量约 98.0%。

市场详情中的机会部分统一为四条并行结构：

- **TECNO 组合建议**：组合分工、优先机会带和整体竞争对象。
- **CAMON**：以高光影像、全焦段人像与视频、精致设计与长期体验为能力支柱；逐档分析 250–600 美元的市场结构、竞争占位和主要竞品，同时解释 250 美元以下的 BOM/品牌边界与 600 美元以上的全能旗舰门槛。
- **POVA**：以年轻科技追潮男为原点，从颜值 ID、AI 科技潮玩体验、手机性能三赛道分析竞争占位；250 美元以下解释成本与体验边界，250–450 美元逐档给出竞争对象和取胜条件，450 美元以上分析品牌与生态门槛及条件性机会。
- **SPARK**：以耐用可靠、续航与长期流畅、可见参数价值为能力支柱；逐档分析 300 美元以下的规模与大众升级机会、竞争占位和主要竞品，并解释 250–300 美元的条件性上沿及 300 美元以上的组合与品牌门槛。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库。
2. 将本目录内的全部文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中，将 **Source** 设为 **Deploy from a branch**。
5. 选择 `main` 分支和 `/ (root)` 目录，点击 **Save**。
6. 等待约 1–3 分钟，GitHub 会生成访问地址：

   `https://你的GitHub用户名.github.io/仓库名/`

## 文件说明

- `.nojekyll`：关闭 Jekyll 处理，确保静态页面按原结构发布。
