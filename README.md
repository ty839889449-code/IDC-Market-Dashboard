# TECNO 26Q2 IDC Market Opportunity Dashboard

Release: v1.2-secure.2

This is a question-and-answer protected GitHub Pages deployment package. Visitors answer the access question before the dashboard is decrypted locally. The plaintext dashboard and answer are intentionally excluded from every deployed file.

## Access question

最好的影像手机品牌？

The answer is case-sensitive and must be distributed separately. It is intentionally absent from this deployment package.

## Deploy to GitHub Pages

1. Create a new repository that has never contained the plaintext dashboard.
2. Upload every file from this package to the repository root.
3. Open **Settings > Pages**.
4. Select **Deploy from a branch**, choose **main**, and choose **/ (root)**.
5. Open the generated github.io URL and test the access-question screen.

Do not add the original HTML, raw IDC data, or the password to the repository, README, issues, or commit history.
