# TECNO CAMON 数据看板

这是一个可直接部署到 GitHub Pages 的静态网页版本，包含 24 个去重市场、9 档价位，以及国家 × 品牌 × 价位三层交互分析。

市场详情在大盘价位变化与高端结构之间，加入“各品牌分价位段同比增量与比例”：可切换品牌，查看九档价位的 25Q1、26Q1、同比净增量、同比增速和档内份额。24 个市场均已使用随本次版本更新的 IDC 源表补齐品牌 × 价位拆分；EE1（俄罗斯）与俄罗斯已合并为一个市场。

每个价位段先在 TECNO 整体层统一呈现市场背景，再分别给出 CAMON、POVA、SPARK 的机会等级、产品机会、当前阵地、竞争占位、核心竞争机型与进入条件，避免重复展示相同的价位段理解。

核心产品数据采用双来源结构：

- **IDC 数据**：市场规模、同比增量、价位段、机型排名和出货量。
- **品牌官网**：Top 销量机型的屏幕、影像、芯片、电池、快充、防护等配置及公开卖点。
- **来源状态**：“品牌官网”表示型号与官网产品页一致；“官网版本差异”表示 IDC 型号与官网地区版/5G 后缀存在差异；“官网待核验”表示暂未检索到完全一致的品牌官网页，不展示未经确认的精确参数。

当前版本共有 983 个产品展示行，其中 820 行由品牌官网支撑，覆盖所展示出货量的 94.5%。

市场详情中的机会部分统一为四条并行结构：

- **TECNO 组合建议**：组合分工、优先机会带和整体竞争对象。
- **CAMON**：以高光影像、全焦段人像与视频、精致设计与长期体验为能力支柱；逐档分析 250–600 美元的市场结构、竞争占位和主要竞品，同时解释 250 美元以下的 BOM/品牌边界与 600 美元以上的全能旗舰门槛。
- **POVA**：以年轻科技追潮男为原点，从颜值 ID、AI 科技潮玩体验、手机性能三赛道分析竞争占位；250 美元以下解释成本与体验边界，250–450 美元逐档给出竞争对象和取胜条件，450 美元以上分析品牌与生态门槛及条件性机会。
- **SPARK**：以耐用可靠、续航与长期流畅、可见参数价值为能力支柱；逐档分析 300 美元以下的规模与大众升级机会、竞争占位和主要竞品，并解释 250–300 美元的条件性上沿及 300 美元以上的组合与品牌门槛。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库。
2. 将本目录内的全部文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中，将 **Source** 设为 **Deploy from a branch**。
5. 选择 `main` 分支和 `/ (root)` 目录，点击 **Save**。
6. 等待约 1–3 分钟，GitHub 会生成访问地址：

   `https://你的GitHub用户名.github.io/仓库名/`

## 文件说明

- `index.html`：完整交互看板，网站首页。
- `.nojekyll`：关闭 Jekyll 处理，确保静态页面按原结构发布。

看板包含 IDC 市场分析数据。若使用公开仓库或公开 GitHub Pages，任何获得链接的人都可以访问。
