# TECNO 26Q2 IDC Market Opportunity Dashboard

Release: v1.2-secure.1

This is a password-protected GitHub Pages deployment package. The plaintext dashboard and access password are intentionally excluded from every deployed file.

## Deploy to GitHub Pages

1. Create a new repository that has never contained the plaintext dashboard.
2. Upload every file from this package to the repository root.
3. Open **Settings > Pages**.
4. Select **Deploy from a branch**, choose **main**, and choose **/ (root)**.
5. Open the generated github.io URL and test the password screen.

Do not add the original HTML, raw IDC data, or the password to the repository, README, issues, or commit history.
